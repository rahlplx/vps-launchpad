# AGENTS.md — plugins/retro/

> Automated retrospective and learning pipeline.
> Generates weekly retros from telemetry + git history + CI data.

## Permissions

```
🟢 AUTO   — Generate retro sessions in brainstorm/sessions/
🟢 AUTO   — Read telemetry snapshots, git log, CI history
🟡 REVIEW — Propose governance rule changes based on learnings
🟡 REVIEW — Modify retro templates or collection scripts
🔴 BLOCK  — Auto-apply governance changes without human review
```

# AGENTS.md — docs/architecture/

> Architecture decision records (ADRs) and system diagrams.

## Permissions

```
🟢 AUTO   — Read any ADR
🟡 REVIEW — Add new ADR or diagram
🔴 BLOCK  — Modify a finalized ADR (create a superseding ADR instead)
```

## ADR naming

`ADR-{NNN}-{slug}.md` — mirrors decision IDs in `context/decisions-index.md`.

## ADR template

```markdown
# ADR-{NNN}: {Title}
Status: PROPOSED | ACCEPTED | DEPRECATED | SUPERSEDED BY ADR-{NNN}
Date: YYYY-MM-DD

## Context
## Decision
## Consequences
## Alternatives rejected
```
